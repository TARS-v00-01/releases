    CodeScene CI changelog¶

    Operation File Previous behavior New behavior Reason Verification
    GitHub workflow update .github/workflows/host-quality.yml Build, test, security, and quality modules had no repository Code Health node. Adds MyPiCarX / Code Health with full history, exact base/head IDs, timeout, summary, and artifact upload. Expose changed-code health without weakening existing jobs. Parse workflow YAML and run the host-quality graph tests.
    Gerrit CI update xWalkGerritQuality.py, xWalkGerritCi.py, xWalkGerritLogServer.py Gerrit ran the module graph without CodeScene metadata or result. Adds a server-rendered Code Health node, exact patch-set environment, retained report, separate review summary, and existing-gate dependency. Analyse the reviewed patch set and preserve the single Verified vote. Run Gerrit CI, graph, and dashboard unit tests.
    Retained Zuul update .zuul.yaml Optional Zuul configuration had no CodeScene job. Adds xwalk-code-health, artifacts, dependencies, and final-gate membership. Keep the retained alternative CI definition aligned. Run xWalkZuulValidator.
    CodeScene adapter xWalkCodeHealth No supported CLI invocation or outage policy existed. Runs verified cs delta syntax when an installed licensed CLI exists and emits deterministic redacted reports. Avoid invented APIs, downloads, and false success claims. Run adapter tests plus missing-CLI analysis.
    CodeScene configuration .codescene/project.json No repository-owned CodeScene source of truth existed. Defines the integrated repository, source root, eight components, and exclusions. Make configuration reviewable and reproducible. Run xWalkCodeHealth validate-config.
    Module mappings .codescene/architectural-components.json CodeScene component paths were undocumented. Maps all requested names to actual integrated paths. Preserve architectural ownership in analysis. Compare manifest with project.json and verify directories exist.
    Exclusions .codescene/analysis-exclusions.txt Generated/output exclusions were not declared. Excludes only actual build, generated, vendor, cache, and Testing paths. Reduce noise without removing production code or tests. Test HostTest inclusion and real generated/build exclusions.
    Secret references GitHub workflow and XWALK_CI_ENV.example No CodeScene policy settings existed. Adds only non-secret CLI/timeout/strict settings; workflow references no CodeScene secret. Native integrations own credentials and fork PRs must remain secret-free. Search modified files for secret expressions and credential values.
    Quality-gate policy xWalkCodeHealth, XWALK_CI_ENV.example No outage or rollout behavior was defined. Defaults to non-blocking unavailable/failure reporting; strict enforcement is explicit. Avoid blocking initial rollout on service availability or historical debt. Test missing CLI in both rollout and strict modes and a degraded CLI result.
    Documentation CodeScene Code Health CI.md, Gerrit CI notes, index Operators lacked supported setup, correlation, troubleshooting, and rollback guidance. Documents product boundaries, GitHub/Gerrit setup, token handling, local use, failures, synchronization, and rollback. Prevent unsupported configuration and credential leakage. Review links, commands, Markdown format, and secret placeholders.
    Test and validation support xWalk-rpi5-hw/CMakeLists.txt, test_xWalkCodeHealth.py, Gerrit CI tests Component, revision, fork-safety, and Code Health graph behavior were untested. Adds a registered host-only CTest plus policy and structural regression tests. Keep both CI implementations aligned and auditable. Execute Python unit tests, YAML validation, bash -n, ShellCheck, CMake, build, and CTest.
